# 学习试卷

根据当前学习进度制作计时模拟试卷，在 Learn（学习模式）右侧独立答题。先定题型、分值与考点，按固定模板逐题编写，汇总整卷审核后才允许开考。

版本 **0.1.1**，插件标识 `learn.exam`，需要支持插件接口版本 **13** 的 LimeA，以及支持工具调用的模型。使用当前会话的模型配置，不需另填模型凭据。本版设计与独立评审记录见 [DESIGN-v0.1.1.md](DESIGN-v0.1.1.md)，首版记录保留在 [DESIGN.md](DESIGN.md)。

## 使用

1. 在「设置 → 插件 → 导入插件」选择构建后的 `dist` 目录并启用。发布至市场后也可从插件市场安装。
2. 切换到 Learn，在右侧入口或加号菜单打开「试卷」。也可以直接在对话里要求按学习进度出卷。
3. 选择题量、时长和难度，可补充考试范围。题型可自动规划，也可展开「题型分配」指定各类题的数量（合计须等于题数）。主对话模型整理已学内容、掌握证据与薄弱点；材料不足时应先询问。
4. 出卷依次经过结构规划、固定模板、逐题生成、一次整卷审核。面板显示题型结构、已生成题数与真实阶段；未开考不展示题目。
5. 点击「开始考试」才开始计时。作答自动保存，可以标记待检查、使用答题卡跳题。离开面板或关闭应用不暂停考试。
6. 点击「检查并交卷」并确认，或到时自动交卷。交卷后查看参考答案，点击「批改试卷」进行评分，再按题回到对话讲解。

支持单选、多选、判断、填空和解答题，3–20 题、5–180 分钟，总分 100；默认 10 题、30 分钟、适中难度。单选、判断题选对得满分，多选题须全部选对才得分，不计过程分。填空题每题 1–4 空，按冻结的每空分值分别计分；精确匹配直接判分，其余非空答案通过模型判定语义等价，避免把不同表达直接判错。解答题支持过程分。填空或解答题存在不确定项时，整题标为待复核，只展示其他题已确认分值，不给出确定总分。

## 保存、计时与恢复

- 保存状态以后台回执为准。输入立即交给后台，只有确认后显示「已保存」；保存未确认时保留本地输入，用户可主动核对重试。
- 开始、保存和交卷都记录请求编号、内容摘要与结果，重复请求不创建第二份作答。响应丢失时先查询已保存结果，不盲目重放。
- 截止时间由插件后台保存。后台到时封存最后已保存的作答，之后不再接受修改。应用关闭期间没有定时器运行，重新启动时先检查并封存过期考试。
- 出卷或批改失败、中断后保留已生成题目和已批改项，可主动继续；不会在重启时自动再次请求模型。关闭标签不取消出卷/批改，停止主运行或停用插件才会取消。
- 每个会话最多一份正在作答的试卷；不同会话独立。重考新增作答记录，不覆盖原成绩。

## 数据与能力边界

复用宿主插件托管数据库 `exam`，由宿主数据库线程管理连接和迁移，初始迁移为 `1000_initial`。试卷、私有答案、出卷进度、作答、评分和模型请求日志存于插件自身目录，不修改主程序数据库。

私有模型请求不继承聊天历史或角色，学习依据由主对话工具参数明确传入。整卷审核文档由数据库中的同一份题目自动生成，包含内部答案与评分规则，不是可独立修改的第二份试卷。审核重新核验答案与条件，不再逐题独立解题。无法确认正确性的题目仍会阻止开考；模型审核不构成正确性保证。

正常 N 题出卷发起 N+2 次插件私有请求：一次规划、N 次逐题生成、一次审核；5 题为 7 次。宿主针对无效结构的内部纠正不计入这个数。实际时间取决于模型，不能保证固定秒数。实质问题只定向修订相应题目，再复核一次；轻微措辞或分布建议不阻断。修订仍不通过就暂停并显示题号与问题类别，用户可以明确选择「再尝试一轮修订」。取消或重启保留修订阶段，不自动重新开始一轮。

0.1.0 的已就绪试卷与作答保持不变；旧暂停卷在主动继续时保留结构有效的题目，接入新的整卷审核流程。升级无需数据库迁移。

出卷和批改会调用当前模型；私有请求用量保存在插件库，宿主当前不汇总到主聊天用量面板。出卷/批改期间占用当前会话，考试作答期间不占用模型运行。

参考答案、评分标准不会在交卷前通过面板或公开工具结果返回。插件属于可信本地代码，隔离用于避免正常使用中的泄题和串会话，不对抗管理员或恶意插件。首版不限制用户在主聊天中提问，也不提供监考、系统时钟防篡改、试卷导入或手写识别。

题目支持纯文本和数学公式，行内使用 `$...$`，独立公式使用 `$$...$$`。使用 KaTeX（数学公式排版库）本地排版，字体随包提供；不执行题目中的网页代码。

## 开发与验证

需要 Node.js（JavaScript 运行环境）24 或以上：

```sh
npm ci
npm test
npm run check
npm run build
```

真实窗口回归需要先构建 LimeA，再在 PowerShell（Windows 命令环境）中执行：

```powershell
$env:LIMEA_REPO_DIR='E:\LimeA'
$env:LIMEA_TEST_APP_DIR='E:\LimeA'
npm run test:desktop
```

测试使用临时用户目录、本地模拟模型和真实 SQLite（嵌入式关系数据库），不调用付费模型，不改用户已安装插件或存档。覆盖五题七次请求、整卷审核和有界定向修订、五题型与填空评分、答案投影、跨会话拒绝、保存/交卷回执丢失、截止竞争、取消迟到结果、恢复、分数边界、中文内容预算，以及桌面公式、窄面板、焦点、连续输入后卸载和重试核对期间继续输入。真实模型的题目质量、推理耗时和费用仍需实际使用评估。

市场仓库根目录的打包命令：

```sh
npm run pack:plugin -- plugins_dev/learn.exam/dist entries/learn.exam.json
npm test
npm run check -- --allow-stale
```

发布新版时保留旧安装包以兼容尚未刷新的目录缓存。

# 学习模拟考试插件设计

状态：0.1.0 历史设计；0.1.1 的出卷与新题型行为由 [新版设计](DESIGN-v0.1.1.md) 取代，其余生命周期约束继续沿用。首版独立复审通过并已实施。用户已确认使用插件托管数据库，先评审再实现。

## 目标与边界

在 Learn 模式的右侧独立标签中，根据当前学习进度制作、审核、完成一张计时试卷。首版包含单选、多选和简答题；3–20 题、5–180 分钟，默认 10 题、30 分钟，总分 100。学习进度由主对话模型根据当前上下文整理并传入，不把“讨论过”等同于“掌握”。依据不足时先询问，不捏造学习记录。

分批制作、整卷发布：逐题生成和审核，最后进行整卷检查，通过后用户主动开始计时。考试期间题目和评分标准固定；不提供提示，交卷后展示解析。模型复核不能证明绝对正确，有争议或不确定的题目不得发布。

不包括试卷导入、手写识别、监考、禁用主聊天、联网考试平台、独立后台模型服务。考试使用本机时间，不承诺防篡改。

## 复用与模块职责

- 插件接口版本 13：`learn.exam`，`placement: tab`，仅 `learn`；工具声明 `local`，历史查询为 `read`。
- 宿主管理数据库、迁移、模型渠道、取消、运行和面板装卸。只使用公开插件接口，不导入宿主内部模块。
- `backend.mjs`：注册工具/命令与生命周期，保持轻量。
- `repository.mjs`：插件托管数据库、短事务、请求与执行记录，不独立创建生产数据库连接。
- `exam.mjs`：试卷、作答和交卷的业务状态、归属和截止时间检查。
- `generation.mjs`：蓝图、逐题出题、独立解答与复核、整卷审核和断点推进。
- `grading.mjs`：确定性客观判分、主观批改与断点恢复。
- `schemas.mjs` / `prompts.mjs`：有界结构校验和各阶段指令。
- `panel.mjs` / `panel.css`：连续试卷、保存反馈和结果展示；后台为状态事实来源。

沿用仓库的 esbuild 构建和市场打包脚本。基础表单使用浏览器原生控件，数学排版使用 KaTeX；无通用表单引擎、供应商客户端或独立任务框架。参考 `games.draw_guess` 的私有请求记录和存储接入，不复制游戏的暂停计时规则。

## 接口与上下文

工具：`prepare`（新建/继续出卷）、`grade`（批改已提交作答）、`review`（读取当前会话已交卷记录）。新建参数只含学习依据、标题、题量、时长和难度，答案由私有模型生成，不能通过公开工具输入传入。

面板命令：读取当前会话试卷/作答、开始考试、保存答案、交卷、暂停出卷。模型工具以宿主提供的 `sessionId` 和 `executionId` 为准；面板命令属于可信插件内部通道，所有对象仍校验会话归属和状态，不声称该通道具有宿主认证的会话身份。无会话时不能直接创建作答，先经 `startRun` 创建学习会话。

`startRun` 占用当前会话；忙碌时提示稍后重试。出卷结束释放运行，答题期间不等待模型。私有请求使用当前模型，不继承角色或聊天历史，学习材料作为明确数据传入。材料中的指令不作为任务指令。

## 数据与状态

独立托管库 `exam`，初始迁移 `1000_initial`；不修改主程序数据库。保存：

1. `papers`：会话归属、学习依据、出卷计划、题目与私有答案、审核证据、版本和制作状态。
2. `attempts`：固定试卷引用、答案、答案修订号、标记、开始/截止/提交时间和评分结果；重考新增记录。
3. `model_requests`：请求目的、关联对象、操作标识、输入、结果、用量和状态。
4. `operations`：工具执行/面板写入标识、会话、动作、规范化载荷摘要和结果；映射与业务写入同事务提交，保证重复执行不重复创建。

试卷状态：`preparing → ready`，失败/停止进入 `paused`；用户继续后恢复制作。已发布试卷内容冻结。

作答状态：`answering → submitted → grading → graded`。批改失败回到 `submitted` 并保留已批改题。主观题允许“不确定”，与零分区分；有待复核题时不显示确定总分。

业务串行队列只保护短读写，不在模型等待期间占锁。持久化意图先于私有请求；结果与阶段推进在同一事务中提交。返回时核对操作标识和取消状态，迟到结果不得修改新状态。公开投影按字段构造，不能直接返回数据库对象。

## 出卷与审核

1. 生成蓝图：每题类型、考点、分值、预计用时；校验题数、总分和范围。
2. 逐题生成题干、选项、答案、评分标准和依据；结构校验后保存候选。
3. 独立解答调用不提供候选答案。客观题规范化比较选项集合；简答题另发审校请求，输入独立解答、原答案和评分标准，检查语义等价、歧义、遗漏、超纲和评分标准，结论为通过/修改/不确定。候选失败最多修订两次，仍失败则暂停并显示原因，不确定不得发布。
4. 保存通过题目后才继续下一题；中断保留候选及已审核题目。
5. 整卷检查覆盖、重复、题间泄题和用时，持久保存问题和需返工题号；问题题重新生成并审核后必须再次整卷检查。单次运行最多一次整卷返工，仍不通过则暂停；主动继续只返工指定题，不重复生成通过题。通过才固定发布版本。

内容预算：学习依据最多 6,000 字符；蓝图最多 6,000 字符；每题持久题目内容序列化后最多 2,200 字符（含题干、选项、答案、评分标准与解析，不含审核日志），整卷最多 44,000 字符。各字符串另有字段上限；提示实际长度不得超过 58,000 字符，超限在调用前拒绝并暂停。整卷只传必要题目、蓝图和学习依据，不传逐次审核日志。公开工具结果不超过 24,000 字节；历史最多十条摘要，指定题号才返回单题结果。覆盖中文、多字节文本和最大题量测试。

## 计时、保存与交卷

- 点击开始才保存开始时间和截止时间；每个会话只允许一份进行中的作答，不阻塞其他会话。
- 每次命令和后台定时检查先判断截止；关闭面板不暂停计时。进程关闭期间不会运行定时器，恢复后先封存过期作答。
- 开始/保存/交卷均携带唯一请求标识，绑定会话、动作和规范化载荷摘要；相同请求返回持久结果，标识复用但内容不同则拒绝。答案保存还校验作答标识和预期修订号；迟到旧版本不得覆盖新版本。只有后台确认成功才显示“已保存”。
- 回执丢失或命令超时后先用读取命令查询操作记录与当前状态；已完成则采用持久结果，不能退回本地旧状态。无法证明完成时保留原请求供用户主动核对重试，不自动更换编号重放。后台业务写入和操作回执同事务提交。读取返回当前状态优先于旧操作回执，避免迟到回执把已交卷界面恢复成作答。
- 输入触发保存，保持焦点与中文组字；提交等待最新答案保存成功，再原子记录封卷状态。保存失败不伪装为已交卷。
- 每次有效编辑立即派发完整快照，前端按派发顺序预留预期修订号，后台串行核验；不把未发送编辑留在面板队列中。关闭面板撤销后续界面调用，但已交付后台的保存继续。失败后停止宣称已保存，用户主动重试时先读最新状态与回执，再以原请求或核对后的修订号提交保留的本地草稿。
- 截止后拒绝新答案，按截止前已保存内容交卷；用户可以查看最后保存状态。重复交卷返回已有结果。
- 考前界面只显示范围与准备状态；开考后只给题干和选项，交卷前任何公开工具/面板投影均不含答案键、参考答案或评分标准。

## 批改、停止与恢复

客观题按已审核答案判分，多选首版全部匹配才得分，空答零分。简答按冻结评分标准逐题请求，校验分数边界；模型“不确定”保存为待复核，不能硬判错误。

失败保留已交卷答案和已批改项，由用户主动继续；成功项不重复调用。运行停止、停用、退出撤销请求；仅关闭面板不取消后台出卷/批改。

启动把未完成私有请求标记中断，暂停出卷/批改并保留断点，不自动重发。不确定执行先查持久记录，不假设跨宿主主库和插件库有事务。

## 界面与验证

延续宿主主题与密度。准备页显示范围、题量、时长和已审核进度；考试页顶部计时/保存状态，主体连续题目，折叠题号导航，底部检查与交卷；结果页逐题得分/答案/解释，允许回到对话复盘。保留键盘焦点、文本选择、组字、窄面板布局与减少动态效果偏好。

自动化验证包括真实 SQLite 的事务、重复交卷、修订冲突、截止边界、跨会话隔离、审核失败、取消迟到结果、重启恢复和公开投影；真实 Electron 用隔离用户目录与模拟模型验证完整路径、模式过滤、公式离线渲染、窄面板、关闭重开与恢复。构建后检查安装包资源、许可和市场清单。真实模型题目质量由后续实际试用评估，不以模拟请求测试代替。

# 试卷工作区界面重构

状态：独立设计评审通过（2026-11-15，exam_flow_review）。用户确认点击“图标＋试卷”只插入输入框标记，补充要求后自行发送。

## 目标与视觉方向

保持宿主紧凑、安静、易读的字体、主题与强调色。替换配置表单和左侧长列表布局，不更改已验证的出卷、审核、计时和判分流程。宽面板使用正文＋右侧题号导航，正文限制阅读宽度；窄面板通过右上角答题卡按钮展开右侧导航。

- 初始页：一个文档图标、一句说明及“试卷”按钮。点击把内部出卷提示追加到当前输入框，展示为“图标＋试卷”，用户补充后发送。无可用宿主接口时明确提示更新主程序，不降级为自动发送。
- 出卷中：居中的紧凑制作区域，清晰的阶段标题；三步“规划结构/逐题编写/整卷审核”、真实题数进度、题型与分值清单。继续/暂停与原因就地显示，审核不伪造百分比，不展示未开考题目或答案。
- 开考前：标题、题型分配与考试规则，单一开始动作。
- 作答：紧凑标题和时长信息、持续可见计时/保存状态；连续试题，题型分节，答案选中状态清楚。右侧按题型分组的题号格区分未答/已答/标记/当前题。导航点击只滚动试卷正文；键盘可操作。
- 复盘：相同正文＋题号导航，标记正确/部分得分/错误/待复核，快速定位各题。参考解析按需展开，讲解动作次级化，避免每题一个强色按钮。
- 历史：替换浏览器原生 select，使用可展开的历史列表，沿用保存完成后切换规则。

## 复用与职责

不新增界面框架或通用任务基础设施。插件复用原生表单、现有 KaTeX、主题变量和保存流程；分出只负责呈现的界面辅助模块（图标、进度、导航），后台状态仍来自 `exam.mjs`。图标使用同一线性风格的小型矢量图形，强调色仅用于主要动作、选中和真实状态。墙纸背景下正文与浮动答题卡保持可读的表面。

宿主补充可选 `WorkspacePanelContext.insertPrompt({label, content}): boolean`，仅向当前草稿追加受限格式的提示文本，不创建会话、不启动模型、不绕过现有发送工具选择。失效实例、隐藏面板、运行中或不同草稿拒绝插入。旧插件无需改变，旧宿主缺省时新插件显示更新提示。

宿主采用通用的有界提示块序列化/识别，不硬编码 learn.exam。标签≤40字符、内容≤6000字符；保留完整原文，文本标记只承担展示用途，不授予工具权限。格式损坏、围栏内示例、知识库标签位于块内部时显示原文。原文仍用于持久化、复制和模型输入；点击标签可查看完整提示。复用图片标注的 Sender 插槽、剪切/粘贴与 ComposerHistory，普通草稿保留原生编辑行为。插件只选择提示内容及标签，不能控制任意宿主消息渲染组件。

## 状态和关键路径

- 插入草稿是同步宿主操作，按当前草稿/会话核对并追加，不覆盖已有输入；插入后聚焦输入框，标记后可继续输入；重复点击相同提示不堆积重复块。焦点请求携带草稿标识，切会话或模式后不抢焦点。
- 删除/剪切、撤销/重做、复制粘贴保持完整原文与知识库位置；发送失败保留，发送成功清空；历史消息仍紧凑展示。
- 导航开合、当前题、展开解析属于面板视图状态，不写考试业务状态。关闭导航不清答案；保存仍立即派发且等待后台确认。滚动或轮询不重建作答控件、不抢输入焦点。批改增量刷新保留当前阅读位置和已展开解析。
- 不新增自动开始/提交/批改行为。所有创建入口只插入草稿；继续出卷、批改和讲解沿用用户点击后启动运行的既有语义。
- 仅插件界面和宿主可选草稿能力改变；无数据库迁移、权限扩张、运行内核变更。

## 验证与交付

宿主单测：序列化往返、损坏/嵌套/围栏文本、长度边界、知识库标签交叠、插槽原文、草稿撤销与选择范围。桌面验证点击不发送、不覆盖已有文本、仅显示图标＋试卷、键盘展开、发送后/重启后紧凑显示而实际请求含完整提示，失效面板不能插入其他草稿。

插件保留 29 项后台测试，真实桌面走出卷→开考→输入→导航→重启→交卷→批改；补宽/窄、明/暗与墙纸表面截图，题号定位与滚动、标记状态、填空未答/部分填写、历史切换、轮询不跳焦点、连续输入卸载等行为。独立代码及视觉审查后构建新包；主程序变更合入 dev，插件按 dev→main 发布新版本，明确紧凑提示需要更新主程序。

## Direction contract

THESIS：把试卷当作专注阅读与作答的工作区；对话负责表达要求，右栏负责进度、考试和复盘。

OWN-WORLD：继承 LimeA 主题、系统字体、柔和中性表面和克制的绿色强调色。明确标题/辅助信息层级，选择行与答题格具有统一的选中反馈；壁纸不削弱正文可读性。

STORY：用户在对话里提出考试要求，看到制作阶段，再主动开考。无论作答或复盘，都能通过右侧题号迅速找到目标题，并保留正在阅读的位置。

FIRST VIEWPORT：紧凑顶栏放标题、时长和历史入口；作答时计时与保存状态持续可见。宽面板主体为最多约 700px 的试题正文与约 160px 的右侧题号导航；窄面板由右上角按钮展开答题卡。制作页以有界宽度的三阶段进度和真实题型清单居中，不堆叠配置表单。

FORM：用户指定的“正文＋右侧导航、对话提示标记”结构，沿用现有应用视觉体系，代码实现；无需视觉世界抽签。

FINISH：完成独立设计、代码与视觉复审，验证真实桌面的宽窄、明暗、壁纸、输入保存和导航行为，并记录交付范围；不改写宿主既有视觉规范。

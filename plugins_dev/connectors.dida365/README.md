# 滴答清单插件（国内版 Dida365）

在 LimeA 中连接国内版滴答清单（`dida365.com`）账号，读取收集箱与各清单中的待办任务，并在当前会话权限控制下创建、修改、完成或删除任务及管理清单。需要支持 `dida365-read-write` 连接权限的新版本 LimeA。

## 使用

1. 在插件市场安装并启用「滴答清单」，或在开发时导入本目录的 `dist`。
2. 在「设置 → 插件」打开滴答清单独立页面，点击「连接滴答清单」，在系统浏览器登录国内版账号并同意授权。
3. 回到 LimeA，在宿主「数据访问权限」区域点击「允许插件使用」。从下一次发送消息开始，模型可调用滴答清单工具。

## 能力与范围

| 工具 | 访问级别 | 说明 |
| --- | --- | --- |
| `list_projects` | `read` | 列出用户自建清单（收集箱请直接在 `get_project_tasks` 中传 `projectId: "inbox"`） |
| `get_project_tasks` | `read` | 读取收集箱（`inbox`）或指定清单的未完成任务与分组，支持关键字/优先级过滤与分页 |
| `get_task` | `read` | 读取单个任务的完整详情与子任务清单 |
| `create_task` | `write` | 创建新任务（支持截止时间 `dueDate`、全天标记、优先级 `0/1/3/5`、重复规则与子任务） |
| `update_task` | `write` | 全量更新已有任务（修改前应先调用 `get_task` 获取原字段，避免清空未传字段） |
| `complete_task` | `write` | 将指定任务标记为已完成 |
| `delete_task` | `write` | 永久删除指定任务 |
| `create_project` | `write` | 创建新清单 |
| `update_project` | `write` | 修改清单名称、颜色、视图模式（不支持修改收集箱） |
| `delete_project` | `write` | 删除清单（不支持删除收集箱） |

滴答清单 Open API 不提供刷新令牌与远程撤销端点；断开连接会立即清除本地加密凭据并撤销插件许可，如需彻底移除授权请前往滴答清单网页端「设置 → 关联应用」手动取消。

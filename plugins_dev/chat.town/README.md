# 陪伴小镇

陪伴小镇 0.2.0 需要 LimeA 0.1.1 或更新的 0.x 版本。

在 LimeA 的「设置 → 插件管理 → 导入插件」中选择本目录下的 `plugin` 文件夹并启用。打开插件详情，在「入住角色」选择角色并保存。聊天右栏可以旋转或缩放场景，也可以暂停或继续当前住客的活动。

住客按设备的本地时间、各自偏好和近期活动选择接下来做的事。早上可以吃早餐或去阳台，白天可以在沙发上休息、用电脑或去镇上逛逛，晚上会按自己的作息回家睡觉。活动在抵达对应点位后开始。

LimeA 运行时，收起或关闭右栏仍会继续推进住客的生活。再次打开右栏时展示后台的当前位置和动作。退住在插件详情页取消勾选并保存。

七处地点各自打包为一个三维模型。角色沿模型中的步行点移动。隐藏时停止绘制和前端刷新，后台根据路点与时间推进。展开时按需载入当前位置的模型，关闭面板释放图形资源。

三维画面铺满右侧标签，地点和可用操作叠在画面上。角色使用当前聊天角色卡的圆形头像，并随步行移动。缺少头像或宿主尚未提供头像接口时，圆形标记显示名字首字。

在聊天里可以查询住客、查询状态、查看可做的事，也可以让当前住客前往一个地点或安排一项活动。工具受理只表示行程已经安排，目的地等走到后才更新为当前位置。后台保存落点、行程和活动停留时间，重启后按存档恢复。

## 开发

使用 `npm ci` 安装固定版本依赖，`npm run build` 打包 Three.js（三维渲染库），`npm test` 校验模型点位、门户、往返路线与活动时序。修改三维模型时保留 `scene_id`、`point_id` 和目标门的 `target_scene`、`arrival_point`。步行线维护在 `plugin/locations.mjs`，点位坐标存于各模型，导出坐标使用米。

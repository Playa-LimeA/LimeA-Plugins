# 陪伴小镇

陪伴小镇需要 LimeA 0.1.1 或更新的 0.x 版本。

在 LimeA 的「设置 → 插件管理 → 导入插件」中选择本目录下的 `plugin` 文件夹并启用。打开插件详情，在「入住角色」选择角色并保存。所有住客生活在同一个小镇，各有自己的住宅。聊天右栏可以旋转或缩放场景，也可以暂停或继续当前住客的活动。

点击右栏顶部的「地图」打开小镇全图。点选一个地点即可浏览那里的三维场景，「家」打开当前角色的住宅。地图上的暖棕色圆点标示角色当前所在的场景。浏览时日程继续推进，点击「回到角色」查看她的当前位置，做客时跟随到对方的家。

右栏底部的角色状态卡显示头像、名字、正在做的事和所在位置。角色在路上时也可查看她的目的地。卡片可收起为一行，展开后可暂停或继续角色的日程。

住客按设备的本地时间、各自偏好和近期活动选择接下来做的事。早上可以吃早餐或去阳台，白天可以用电脑、到公园看水或在路边待几分钟，晚上会按自己的作息回家睡觉。活动在抵达对应点位后开始。

LimeA 运行时，收起或关闭右栏仍会继续推进住客的生活。再次打开右栏时展示后台的当前位置和动作。退住在插件详情页取消勾选并保存。

七种场景各自打包为一个三维模型，各住宅共用同一份住宅模型。角色沿模型中的步行点移动。隐藏时停止绘制和前端刷新，后台根据路点与时间推进。展开时按需载入当前位置的模型，关闭面板释放图形资源。

三维画面铺满右侧标签，地点和可用操作叠在画面上。街角、公园、店铺等公共场景显示实际在场的住客，住宅显示房主和到访的住客。当前聊天角色使用角色卡的圆形头像，其他住客显示名字首字。角色在走动时，标记会沿各自的路线移动。

在聊天里可以列出入住角色、查询住客状态和可做的事，也可以安排当前角色前往地点、进行活动或上门拜访。拜访时先从住客名单取得对方的标识。房主在自己的住宅时可以出发，走到门口会再确认一次。回家会前往自己的住宅。工具受理只表示行程已经安排，目的地等走到后才更新为当前位置。后台保存落点、行程和活动停留时间，重启后按存档恢复。

LimeA 0.1.1 的聊天工具可以查询当前住宅和目的地的房主姓名。聊天自动附带这些姓名需要安装支持小镇拜访提示的宿主版本。

## 开发

使用 `npm ci` 安装固定版本依赖，`npm run build` 打包 Three.js（三维渲染库），`npm test` 校验模型点位、门户、往返路线与活动时序。修改三维模型时保留 `scene_id`、`point_id` 和目标门的 `target_scene`、`arrival_point`。步行线维护在 `plugin/locations.mjs`，点位坐标存于各模型，导出坐标使用米。

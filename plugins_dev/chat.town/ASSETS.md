# 陪伴小镇素材说明

- 安装包 `assets/` 内的住宅、街角、咖啡厅、公园、面包店、家具店和超市模型用于陪伴小镇场景，随插件分发。模型的独立复用遵循各素材权利人的授权。
- 安装包中的 `assets/town-map.svg` 是陪伴小镇的示意地图，随插件分发。
- 安装包中的 `assets/banner.png` 由用户提供，用作详情页横幅。横幅随插件分发，独立复用遵循素材权利人的授权。
- 安装包中的 `assets/icon.png` 使用内置图像生成，作为详情页、侧栏和插件市场的透明底图标。
- 插件源码和文档使用本目录的 [MIT 许可证](./LICENSE)。
- 插件使用 Three.js（三维渲染库），许可见安装包中的 `vendor/THREE-LICENSE.txt`。

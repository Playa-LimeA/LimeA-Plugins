# 百度网盘（Baidu Netdisk）连接器插件

连接你的百度网盘账号，在 LimeA 对话中通过宿主受限代理与会话审批机制浏览、搜索和整理授权目录中的文件。

## 权限范围说明

- 个人开发者创建的百度网盘开放平台应用默认仅能访问专属应用目录 `/apps/<应用名>/`（例如 `/apps/LimeA/`），无法读取网盘根目录下的其他私人文件夹。
- 本插件仅支持目录浏览、关键字搜索、容量配额查询、元数据查询及文件夹新建、重命名、移动、复制与删除，不提供直链下载（`dlink`）或大文件流式传输。
- 所有写入与整理操作均受 LimeA 会话权限档位保护，在「请求审批」模式下逐次弹出确认卡片。

## 提供的模型工具

### 只读工具
- `get_quota`：查看网盘总空间与已用空间配额
- `list_files`：浏览指定目录的文件与子文件夹
- `search_files`：按关键字搜索授权目录内的文件
- `get_file_metas`：按 `fs_id` 列表查询文件元数据

### 写外部服务工具（受审批保护）
- `create_folder`：在授权目录下新建文件夹
- `rename_file`：重命名文件或文件夹
- `move_files`：移动文件或文件夹到目标目录
- `copy_files`：复制文件或文件夹到目标目录
- `delete_files`：删除指定文件或文件夹（不可删除 `/apps/<应用名>` 顶层目录）

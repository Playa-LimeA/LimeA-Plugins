# 你画我猜

与当前聊天角色轮流画画、猜词。用户可以边画边等角色猜，角色也能观察自己实际画出的画面，继续补画或修改。以陪玩和表达为主，允许抽象、笨拙的画法，不设积分。

当前正式版本为 **0.2.2**，需要支持插件接口版本 **12** 的 LimeA 和支持图片输入的模型。插件详情页提供玩法说明，不包含账号连接。产品方向和后续事项见[设计文档](DESIGN.md)。

- 开发目录：`plugins_dev/games.draw_guess`。
- 通用画板由 LimeA 内置；本插件负责词库、选词、轮次与游戏交互。
- 插件标识：`games.draw_guess`。
- 源码使用 [MIT（宽松开源许可证）](LICENSE)，图标与 CC0（公共领域贡献声明）音效见[素材说明](ASSETS.md)。

## 安装与游玩

使用支持插件接口版本 12 的 LimeA，在「设置 → 插件市场」安装「你画我猜」，然后启用。开发时也可以在「设置 → 插件 → 导入插件」选择本目录构建出的 `dist`。切到 Chat（聊天模式），从右侧「小游戏」打开「你画我猜」；也可以从插件管理的详情页查看玩法说明。旧版主程序需要先更新，单独安装插件不能补齐共享画板与私有模型能力。

选择谁先画和每轮时长（3／5／10 分钟，默认 5 分钟），点击开始。也可以在聊天里邀请角色玩，由模型调用工具打开游戏。

- 开场单独生成一批词；画家每轮三选一，不提供自命题。展示过的三个词全部退出本场后续候选。
- 出题期间显示遮罩和「请稍等，正在出题中…」。你选好词后直接进入画板并开始计时，角色定期看实际画面猜测，请求期间仍可继续画。
- 双方都有标准题目的字数提示；猜测请求只得到字数，得不到题目或候选。同义词仍可使用不同字数。
- 画板使用图标工具栏，支持笔画、圆形、方框、橡皮、颜色和 1～24 px 粗细滑动条。画板获得焦点时，Ctrl+Z 撤销、Ctrl+Y 重做，也支持 Ctrl+Shift+Z；聊天输入框中的文字编辑不受影响。
- 颜料桶按当前颜色填充点击处相连的区域，支持手绘闭合轮廓；轮廓有缺口时颜色会流到外侧，不自动补缝。填色可撤销、重做、用橡皮删除，重启后保留；后来擦掉边界不会让旧填色重新扩散。
- 绘画、擦除、填色、撤销和重做都有轻量音效。右上角「音效」可调整音量、整体静音或单独关闭画笔声，设置自动记住。移动时才有画笔声，松手、暂停或隐藏面板时停止；恢复存档不补播声音。
- 角色画时，它秘密选词，分批画图并观察实际画面，可以继续添加或删除图形。你随时在猜测框输入答案。
- 猜中、到时或点击揭晓后，立即显示答案和「再来一轮 / 下次再玩」，再来一轮默认交换双方。没有积分或速度比较。
- 等待选词和准备首批绘画不计时；开始后模型思考计入时间。暂停、离开面板或中断保留画作，继续时恢复剩余时间。
- 用户停止主运行、退出或停用插件后，不自动重发未完成请求。当前已保存的画作和状态留在本地。

本版逐批显示图形，尚无逐笔动画。猜测按完整答案或生成时的确切同义词匹配，不做模糊语义裁判；建议只输入词语，不用“是不是……”长句。真实模型的延迟和画法需实际体验调整，抽象画风不视为错误。

## 数据与宿主边界

插件复用 LimeA 的共享画板与私有模型接口，安装包不携带绘图库、模型凭据或独立供应商客户端。每个私有请求不继承普通聊天历史；出题不继承角色，选词、作画和猜测继承当前角色设定。请求沿用本次主运行选定的模型与思考设置。

词库、候选、请求日志、画板文档和轮次记录保存在宿主分配的 `games.draw_guess` 插件数据库 `game`，首条迁移为 `1000_initial`。词库和私有绘画内容不进入公开工具详情。每次绘画与猜测请求保存意图、结果状态和用量；私有用量目前保存在插件日志，尚未合入聊天输入框的用量统计。

画板文档的类型、校验和渲染由宿主共享组件维护，首版与插件轮次一起存入托管数据库；尚未做跨应用的独立画作库，也未改动 Work（办公模式）的画布占位。每次只保留最新观察快照用于请求，原始笔画文档会保存，重启重新渲染取图。

结束时把最近已揭晓轮次的简短公开记录交回聊天；角色也可用记录工具查询。未揭晓题目、候选和剩余题库不进入这份记录。启用插件仍代表信任本地代码，这种信息隔离不对抗本机管理员或恶意可信插件。

## 开发与验证

需要 Node.js（JavaScript 运行环境）24 或以上，在本目录执行：

```sh
npm ci
npm test
npm run build
```

在主程序完成构建后，可通过环境变量指定主仓库与独立桌面构建目录，再运行 `npm run test:desktop`：

```sh
LIMEA_REPO_DIR=/path/to/LimeA LIMEA_TEST_APP_DIR=/path/to/built-app npm run test:desktop
```

桌面测试使用独立临时用户目录和本地模拟模型，验证真实图片发送、三选一保密、字数提示、出题遮罩、选词自动开始、图标与滑动条、画板快捷键、闭合与开放区域填色、擦掉边界后的稳定性、填色撤销重做和重启恢复、模型看到填色画面、本地音效解码和静音设置、未松开鼠标时观察画面、请求期间继续画、角色看自己的画、即时结果、迟到操作丢弃、窄面板，以及暂停后重启并继续原画作，不调用付费模型。不会修改用户已安装的游戏或真实存档。

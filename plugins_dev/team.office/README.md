# 团队办公室

在支持插件接口版本 15 的 LimeA（桌面智能体应用）中，通过「设置 → 插件市场」安装「团队办公室」，再从「插件」里启用。开发时也可通过「设置 → 插件 → 导入」选择本目录下的 `plugin` 文件夹。进入团队模式，点击聊天标题旁的办公楼按钮。

在「设置 → 插件」中点击「团队办公室」，可以查看场景封面、打开方式和功能说明，并从详情页的「管理」菜单启停或更新插件。

办公室默认打开通用办公层。点击左上角的楼层标题展开楼栋图，点图中的任一层即可切换。当前楼层用深绿色标出。通用办公层每层有 12 个普通工位，超出后增加办公楼层。已指定的助理出现在总裁层的助理办公室。一楼展示公司招牌、前台和等候区。

总裁工位显示本机用户的头像，头顶固定显示「总裁」。宿主通过声明的 `profile:avatar` 提供显示用头像。用户尚未设置头像时显示用户图标。

按住楼层画面拖动可绕着办公室旋转，点击「复位」回到默认视角。点击地图头像或本层成员会打开状态看板，显示真实工作状态、正在做的事和所在区域。私聊从团队左侧打开。

待命成员会从 24 个场景动作里选择，例如在水吧等咖啡，或者走到休闲区坐一会。头像气泡与看板的「正在做」同步。每层最多 12 位成员可以同时离座，离开工位时沿楼层过道移动。收到真实工作状态时立即更新看板，外出的头像沿原路回到工位。动画随面板可见性暂停和恢复。

在楼层图上向上滚动鼠标滚轮放大，向下滚动缩小。也可以用右上角的加减按钮调整。

插件目录可直接安装。三维场景及工位坐标来自已定稿的楼层模型。图形设备无法加载三维场景时，自动显示当前楼层的底图，仍可缩放和点击头像。桌面应用保存座次与计算状态。修改三维依赖时，在本目录运行 `npm ci` 和 `npm run build` 重建插件包内的运行模块。

# 鲨鱼咬牙插件

可选安装的 LimeA 游戏插件。游戏、Three.js、模型和图标在本目录中维护；主程序提供插件面板、后台命令及托管数据库接口。市场条目见 [插件汇总](../../README.md)。

当前正式版本为 **0.4.2**，需要支持插件接口版本 **12** 的 LimeA。插件详情页提供玩法说明，不包含账号连接。

## 构建与安装

需要 Node.js 24 或更高版本。先进入本目录 `plugins_dev/games.shark`：

```sh
npm ci
npm test
npm run build
```

在支持插件接口版本 12 的 LimeA 中打开“设置 → 插件”，首次安装时导入本仓库的 `dist` 目录并启用。已安装的用户在对应插件一行点击“从目录升级”，选择新版 `dist`，重启后生效。普通导入会拦截重复标识。切换到 Chat，打开“小游戏”，点击“鲨鱼咬牙”图标；也可以从插件管理的详情页查看玩法说明。

可以点击模型中的牙齿，也可以点击底部编号。每局固定一颗随机坏牙，踩中就合嘴；点击“再来一局”重新开始。单人模式继续保留；点击“角色陪玩”，沿当前会话的角色和模型开始双人游戏。模型也可以调用工具主动开启，宿主会自动展开游戏面板。

0.2.0 起对局通过宿主托管数据库接口写入插件数据目录下的 `databases/rounds.sqlite`，迁移从 `1000_initial` 开始。升级时自动接管旧版 `rounds.sqlite`，保留其原文件；后续只读取托管库，不会用旧文件覆盖新进度。数据按模式和会话区分；未发送消息的草稿使用独立草稿对局。切换会话不会继承另一会话的对局，重启后恢复存档。插件停用后停止界面、声音与渲染，卸载或更新安装目录不删除数据目录。

## 权限与边界

沿用 LimeA 的可信本地插件模型：启用代表信任插件代码，权限声明用于说明与审计，并非系统沙箱。此插件只使用自己的数据目录，无网络账号、模型密钥或终端需求。前端通过宿主命令通道调用插件后台，后台结果保存成功后才播放动作。

源代码采用 [MIT 许可证](LICENSE)。模型、可编辑模型文件和图标的授权单独见 [素材说明](ASSETS.md)，不属于源代码 MIT 授权范围。安装包同时包含代码许可证、素材说明及 Three.js 的许可证。

## 双人陪玩（0.3.0）

每局随机先手，用户和角色轮流选牙。危险牙齿只在插件库中保存，模型只收到已按和剩余牙齿。轮到用户时等待，不请求模型；轮到角色时通过工具选择，保存成功后面板播放按牙和合嘴动画。

一局结束累计比分，模型收到结果后回应并等待“再来一局 / 下次再玩”。再来一局仍属于当前运行，下次再玩或提前结束会通知模型收尾。全局停止、失败或重启会暂停并保留本局危险牙、落子及比分，点击“继续陪玩”恢复。普通回复进行时不能另开游戏，也不能操作单人牙齿。

`1000_initial` 保持不变，`1001_companion_matches` 新增双人存档，升级保留原单人存档。模型工具为 `start` 和 `press_tooth`，宿主给它们分配稳定函数名；`match-action` 只接受当前会话的局标识和版本，重复或过时点击不能再次计分。模型连续漏调用时由宿主暂停，用户可以继续重试。多局运行仍遵守宿主消息容量和上下文错误边界。

0.3.2 起计分板和回合提示使用宿主当前会话绑定的角色卡姓名；草稿沿用所选角色，旧宿主未提供姓名时显示默认称呼。长姓名会省略显示，悬浮可查看全名。0.3.3 更新游戏入口与市场图标。0.3.4 将图标缩至 320×320，减小市场与安装包下载体积。0.3.5 将源码迁入插件汇总仓库，并随安装包提供代码许可证与素材授权说明。0.4.0 增加独立详情页和横幅，需要接口版本 11 的宿主。0.4.1 更新详情页横幅。
